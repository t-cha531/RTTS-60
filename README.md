# RTTS-60

## 自作キーボード全般の特徴

### キースイッチのホットスワップ対応
好きなキースイッチを使えます。(Choc V1という規格であれば)
キーボードの押し心地を自分の理想的なものにすることができます。

### キーマップが自由
キーマップとは、キーを押したときに実際に何の文字(キーコード)がPCへ送信されるか、という割り振りのことです。
これを使うことで使用用途の低いキー(capslockとか)を別のキーに変更したりできます。
もちろんそれだけでなく、全く違うレイアウトでキーボードのマッピングをすることもできます。(使いやすいかは別にして)
また、通常のキーボードの多くは対応していない、レイヤー機能というものも使用できます。
レイヤー機能は多くの機能がありますが、例えばレイヤーキーを押しながら、スペースキーを押すとエンターとして認識されるといったよう動作ができます。
通常のキーボードでShiftキーを押しながら「1」キーを押すと「！」になるような感じです。
こういった動作を自分の使いやすいように作り込むことができます。

### 左右分割型
このキーボードは左右分割型を採用しています。
左右分割であることのメリットは様々な場所で語られていますが、主に以下が挙げられます。
- 肩こり軽減
- 疲労軽減

## このキーボード特有の特徴

### 親指キー
このキーボードには親指で押すことを想定して配置されたキーが左右それぞれ3つあります。
通常のキーボードでは親指で押すのはスペースキーくらいだと思いますが、親指キーは思ったより器用に動かすことができます。
それをスペースキーだけしか使用しないのはもったいないのです。なので、3つ用意しました。
例えば私はこういった用途で使用しています。
 - 右手の親指にバックスペースキーを配置
   - 使用用途の高いわりに離れていて押しづらいキーをホームポジションのまま押せるように
 - 左手の親指にShiftキーを配置
   - 大文字アルファベットを入力する際の小指でシフト押すの大変問題を解消
その他、上に記載したレイヤーキーは主に親指のキーに担当させています。

### 通常のキーボードと同じ物理配置
通常のキーボードの物理配置はロウスタッガードと呼ばれ、キーが横にズレて配置されているものです。
これはもともとタイプライターが発明された際に、その構造上の制約からできたものがデファクトスタンダード化したもので使用する上での合理性はありません。
そのため、自作キーボードの多くは、指の長さに合わせてキーが縦にズレたカラムタッガードと呼ばれるものや、省スペースのためにズレのない格子上のオーソリニアといったものが使われます。
しかし、そういった配列には以下のデメリットも存在します。
- 慣れるまで使いづらい
- 慣れると逆に通常のキーボードが使いづらくなってしまう
通常のキーボードを使用する際にも同じように文字入力できるように、RTTS-60は通常のキーボードと同じロウスタッガードを採用しています。
初めての自作キーボードでも違和感が少なく使い始めることができます。

### 薄型&省スペース
キーボード全体が薄くなるように、ロープロファイルのスイッチを採用しています。
ロープロファイルでないスイッチを採用したキーボードは、高さがある分リストレストを使用することが前提だったりします。
このキーボードは、リストレストがなくとも無理なく使用できる高さになっています。
また、文字キーが一般のキーボードと同じように使えることを要件とし、なるべく省スペース化するという思想で設計されているため、右手側のキーは列が削減されています。
キーが減っているのがデメリットに感じるかもしれませんが、手を大きく動かさずとも一番端のキーまで指が届くため、疲労軽減やタイプ速度の向上に繋がるといった効果が期待できます。
